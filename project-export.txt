### Problemen en oplossingen

| Probleem | Oorzaak | Oplossing |
|---|---|---|
| `Get-NetAdapter` niet herkend | Per ongeluk in `cmd.exe` gewerkt in plaats van PowerShell | Overgeschakeld naar PowerShell met `powershell` |
| Ping tussen servers faalde met `TimedOut` | Windows Defender Firewall blokkeert ICMP standaard | Tijdelijk uitgeschakeld voor testen; structurele oplossing met gerichte firewallregels uitgewerkt tijdens de DNS-taak |
| `Install-ADDSForest` gebruikte Windows Server 2016 als functional level | Parameterwaarde `WinThreshold` komt overeen met Windows Server 2016 | Correcte waarde `Win2025` gebruikt voor `-ForestMode` en `-DomainMode` |
| `Set-ADForestMode` / `Set-ADDomainMode` gaf â€œInsufficient access rightsâ€ | Het `vagrant`-account was na de promotie geen lid van de vereiste beheergroepen | Account expliciet toegevoegd aan `Domain Admins` / `Enterprise Admins`, gevolgd door een volledige herstart |
| `vagrant up` crashte met `WinRM::WinRMAuthorizationError` na AD-promotie | Standaard WinRM negotiate/NTLM-authenticatie werkt niet meer nadat de server domeincontroller wordt | WinRM-transport omgezet naar `plaintext` met `basic_auth_only = true`; retry-limiet en delay verhoogd |
| Na een gecrashte `vagrant up` kon server1 niet opnieuw worden aangemaakt (`VERR_ALREADY_EXISTS`) | Verweesde VirtualBox-map bleef achter | VM uitgeschreven met `VBoxManage unregistervm --delete` en de achtergebleven map verwijderd |
| DNS-firewallblok gaf een parameterconflict | `DisplayName` werd tegelijk gebruikt als selectie- en wijzigingsparameter | Selectie via `Name` en hernoeming via `NewDisplayName` |
| Directe HTTPS-aanvraag naar `/CertSrv` werkte, maar HTTP gaf `403.4` | De Certificate Services-pagina vereist HTTPS | Aparte HTTP-redirectsite toegevoegd die HTTP 302 stuurt naar de HTTPS-startpagina |
| PowerShell-authenticatie na een automatische HTTP-naar-HTTPS-redirect gaf problemen | Credentials worden niet betrouwbaar meegestuurd over de redirect | Redirect expliciet gecontroleerd zonder credentials; daarna pas de HTTPS-bestemming opgevraagd met credentials |
| `server3-publish-root-ca` faalde omdat het publicatielog ontbrak | De samengestelde `powershell.exe -Command`-argumenten startten `certutil` niet betrouwbaar in de Scheduled Task | Script aangepast zodat `cmd.exe` de `certutil`-opdracht uitvoert met een eenvoudige `>`- en `2>&1`-omleiding naar het logbestand |
| Client ontving de CA-trust-GPO niet | De client was nog geen lid van het domein | Client automatisch toegevoegd aan `WS26-JD.hogent`; daarna werd de GPO toegepast en verscheen het Root-CA-certificaat in de Trusted Root-store |
| `WinRM::WinRMAuthorizationError` tijdens de client-domeinjoin | `Add-Computer -Restart` herstartte de client terwijl Vagrant nog verbonden was | Verwacht gedrag; na de herstart werd de verbinding hersteld en slaagde de verdere provisioning |
| `vagrant ssh` leek mogelijk geblokkeerd door de firewall | Inkomend verkeer wordt standaard geblokkeerd | De bestaande regel `OpenSSH-Server-In-TCP` bleef ingeschakeld; SSH werd getest op alle vier VMâ€™s met actieve firewall |

## 6. Conclusie

- Het uitrollen van een Windows Server-labomgeving is volledig herhaalbaar gemaakt met Vagrant en idempotente PowerShell-scripts.
- De omgeving omvat nu Active Directory, DNS, DHCP, Certification Authority, Web Enrollment, IIS, RSAT, client-domeinjoin, firewallbeleid en automatische verificatie.
- De belangrijkste leerervaring was dat Active Directory, DNS, certificaten, IIS en firewallregels sterk van elkaar afhankelijk zijn: een CA heeft correcte DNS nodig, Web Enrollment heeft een correct certificaat nodig, en verificatie vanaf een andere server controleert de volledige keten.
- Idempotentie is essentieel gebleken: scripts moeten veilig opnieuw kunnen draaien zonder dubbele objecten of onnodige wijzigingen aan te maken.
- De Vagrantfile is zo opgebouwd dat de volgorde van afhankelijkheden automatisch wordt gerespecteerd: eerst de domeincontroller, daarna DNS en CA, vervolgens de CA-afhankelijke server1-configuratie en ten slotte de client.
- Bij een volgend project zou ik vanaf het begin een aparte verificatieprovisioner per dienst toevoegen, zodat configuratie en acceptatietest gescheiden blijven.
- De meeste tijd ging verloren aan Windows-specifieke gedragingen: firewallregels, WinRM na domeinpromotie, certificaatbindingen in IIS, authenticatiegedrag bij redirects en Scheduled Task-quoting in PowerShell.

<#

    Installeert de geselecteerde RSAT-tools op de Windows 11-client.

.DESCRIPTION
    Installeert alleen:
    - Active Directory DS/LDS Tools
    - DNS Server Tools
    - DHCP Server Tools
    - Group Policy Management Tools

    Reeds geinstalleerde onderdelen worden overgeslagen.
    Domeinjoin en remote beheer worden niet door dit script geconfigureerd.

if ($env:COMPUTERNAME -ine "client") {
    throw "Dit script is bedoeld voor de Windows 11-client."
}

Import-Module Dism

    "Rsat.ActiveDirectory.DS-LDS.Tools~~~~0.0.1.0"
    "Rsat.Dns.Tools~~~~0.0.1.0"
    "Rsat.DHCP.Tools~~~~0.0.1.0"
    "Rsat.GroupPolicy.Management.Tools~~~~0.0.1.0"
)

    $Capability = Get-WindowsCapability `
        -Online `

    if (-not $Capability) {

===== BEGIN: scripts\client\verify-ca.ps1 =====
#Requires -RunAsAdministrator

param(
    [string]$DomainName = "WS26-JD.hogent",
    [string]$CACommonName = "WS26-JD-Root-CA"
)

$ErrorActionPreference = "Stop"

$Computer = Get-CimInstance Win32_ComputerSystem

if (
    -not $Computer.PartOfDomain -or
    $Computer.Domain -ine $DomainName
) {
    throw "De client moet lid zijn van $DomainName en na de domeinjoin herstart zijn."
}

$CAConfig = "server3.$DomainName\$CACommonName"

$CertificatePath = Join-Path `
    $env:TEMP `
    ("WS2-ExpectedRootCA-" + [guid]::NewGuid().ToString("N") + ".cer")

try {
    Write-Output "Publiek certificaat van de huidige CA ophalen..."

    $CertutilArguments = @(
    '-f'
    '-config'
    $CAConfig
    '-ca.cert'
    $CertificatePath
    )

    & certutil.exe @CertutilArguments

    if ($LASTEXITCODE -ne 0) {
        throw "Ophalen van het CA-certificaat mislukt. Exitcode: $LASTEXITCODE"
    }

    $ExpectedCertificate =
        [System.Security.Cryptography.X509Certificates.X509Certificate2]::new(
            $CertificatePath
        )

    $ExpectedThumbprint = $ExpectedCertificate.Thumbprint

    Write-Output "Verwachte Root-CA-thumbprint: $ExpectedThumbprint"
    Write-Output "Computerbeleid vernieuwen..."

    & gpupdate.exe /target:computer /force /wait:120

    if ($LASTEXITCODE -ne 0) {
        throw "Vernieuwen van computerbeleid mislukt. Exitcode: $LASTEXITCODE"
    }

    $Deadline = (Get-Date).AddMinutes(3)
    $RootCertificate = $null

    do {
        $RootCertificate = Get-Item `
            -Path "Cert:\LocalMachine\Root\$ExpectedThumbprint" `
            -ErrorAction SilentlyContinue

        if ($RootCertificate) {
            break
        }

        Write-Output "Huidige Root-CA nog niet aanwezig; opnieuw controleren over 10 seconden..."
        Start-Sleep -Seconds 10
    }
    while ((Get-Date) -lt $Deadline)

    if (-not $RootCertificate) {
        throw "Huidige Root-CA $ExpectedThumbprint ontbreekt in Trusted Root na beleidsvernieuwing."
    }

    $Now = Get-Date

    if (
        $RootCertificate.NotBefore -gt $Now -or
        $RootCertificate.NotAfter -le $Now
    ) {
        throw "Het Root-CA-certificaat is momenteel niet geldig."
    }

    Write-Output "Root-CA aanwezig:"

    $RootCertificate |
        Format-List Subject, Thumbprint, NotBefore, NotAfter |
        Out-String -Width 200 |
        Write-Output

    $IntranetUrl = "http://intranet.$DomainName"

    Write-Output "Intranet testen: $IntranetUrl"

    $Response = Invoke-WebRequest `
        -Uri $IntranetUrl `
        -UseBasicParsing `
        -TimeoutSec 30

    if ($Response.StatusCode -ne 200) {
        throw "Onverwachte HTTP-status voor intranet: $($Response.StatusCode)"
    }

    Write-Output "Intranet is bereikbaar: HTTP 200."
}
finally {
    Remove-Item `
        -Path $CertificatePath `
        -Force `
        -ErrorAction SilentlyContinue
}

===== BEGIN: scripts\configure-dns-registration.ps1 =====
<#
.SYNOPSIS
    Voorkomt ongewenste automatische DNS-clientregistratie.

.DESCRIPTION
    Mode Server:
        Schakelt registratie uit op de NAT-interface.
        Laat de Host-Only-instelling ongewijzigd.

    Mode Client:
        Schakelt registratie uit op alle actieve netwerkadapters.

    Wijzigt geen IP-adressen, DNS-serveradressen of gateways.
    Verwijdert geen bestaande DNS-records.
#>

param(
    [Parameter(Mandatory = $true)]
    [ValidateSet("Server", "Client")]
    [string]$Mode
)

$ErrorActionPreference = "Stop"

$Adapters = @(
    Get-NetAdapter | Where-Object { $_.Status -eq "Up" }
)

if ($Adapters.Count -eq 0) {
    throw "Geen actieve netwerkadapters gevonden."
}

if ($Mode -eq "Client") {
    $TargetAdapters = $Adapters
} else {
    # In deze labomgeving heeft NAT een default gateway.
    # De Host-Only-interface heeft geen default gateway.
    $TargetAdapters = @(
        $Adapters | Where-Object {
            $Config = Get-NetIPConfiguration -InterfaceIndex $_.ifIndex
            $null -ne $Config.IPv4DefaultGateway
        }
    )

    if ($TargetAdapters.Count -ne 1) {
        throw "Verwacht precies een actieve NAT-interface met IPv4-default gateway."
    }
}

foreach ($Adapter in $TargetAdapters) {
    Set-DnsClient -InterfaceIndex $Adapter.ifIndex `
        -RegisterThisConnectionsAddress $false `
        -UseSuffixWhenRegistering $false

    Write-Host "DNS-clientregistratie uitgeschakeld: $($Adapter.Name)"
}

# Controleer of de wijziging effectief toegepast is.
foreach ($Adapter in $TargetAdapters) {
    $DnsClient = Get-DnsClient -InterfaceIndex $Adapter.ifIndex

    if ($DnsClient.RegisterThisConnectionsAddress) {
        throw "DNS-clientregistratie staat nog aan op $($Adapter.Name)."
    }
}

Get-DnsClient |

#Requires -RunAsAdministrator

param(
    [Parameter(Mandatory = $true)]
    [ValidateSet(
        "192.168.26.10",
        "192.168.26.20",
        "192.168.26.30"
    )]
    [string]$IPAddress
)

$ErrorActionPreference = "Stop"

$PrefixLength = 24
$NatGateway = "10.0.2.2"

$ExpectedAddresses = @{
    server1 = "192.168.26.10"
    server2 = "192.168.26.20"
    server3 = "192.168.26.30"
}

$Machine = $env:COMPUTERNAME.ToLowerInvariant()

if (-not $ExpectedAddresses.ContainsKey($Machine)) {
    throw "Dit script is uitsluitend bedoeld voor server1, server2 en server3."
}

if ($IPAddress -ne $ExpectedAddresses[$Machine]) {
    throw "Verkeerd IP-adres voor ${Machine}: verwacht $($ExpectedAddresses[$Machine])."
}

# ------------------------------------------------------------
# 1. Controleer de twee actieve netwerkadapters van dit lab.
# ------------------------------------------------------------

$Adapters = @(
    Get-NetAdapter |
        Where-Object { $_.Status -eq "Up" }
)

if ($Adapters.Count -ne 2) {
    throw "Verwacht precies twee actieve adapters; gevonden: $($Adapters.Count). Geen wijzigingen uitgevoerd."
}

# NAT herkennen aan de IPv4-default-route, niet aan de naam.
$DefaultRoutes = @(
    Get-NetRoute `
        -AddressFamily IPv4 `
        -DestinationPrefix "0.0.0.0/0" `
        -PolicyStore ActiveStore |
        Where-Object { $_.InterfaceIndex -in $Adapters.ifIndex }
)

$NatIndexes = @(
    $DefaultRoutes |
        Where-Object { $_.NextHop -eq $NatGateway } |
        Select-Object -ExpandProperty InterfaceIndex -Unique
)

if ($NatIndexes.Count -ne 1) {
    throw "Verwacht precies een NAT-interface met gateway $NatGateway. Geen wijzigingen uitgevoerd."
}

$NatIndex = $NatIndexes[0]

$InternalAdapters = @(
    $Adapters |
        Where-Object { $_.ifIndex -ne $NatIndex }
)

if ($InternalAdapters.Count -ne 1) {
    throw "Kan niet precies een interne interface selecteren. Geen wijzigingen uitgevoerd."
}

$InternalAdapter = $InternalAdapters[0]
$InternalIndex = $InternalAdapter.ifIndex

if ($DefaultRoutes.InterfaceIndex -contains $InternalIndex) {
    throw "De interne interface heeft een IPv4-default-route. Controleer dit handmatig; geen wijzigingen uitgevoerd."
}

Write-Output "Machine: $Machine"
Write-Output "NAT-interface beschermd: index $NatIndex"
Write-Output (
    "Interne interface: {0}, index {1}" -f
    $InternalAdapter.Name, $InternalIndex
)
Write-Output "Gewenste configuratie: $IPAddress/$PrefixLength"

# ------------------------------------------------------------
# 2. Controleer bestaande IPv4-configuratie.
# ------------------------------------------------------------

$AddressesElsewhere = @(
    Get-NetIPAddress -AddressFamily IPv4 -PolicyStore ActiveStore |
        Where-Object {
            $_.IPAddress -eq $IPAddress -and
            $_.InterfaceIndex -ne $InternalIndex
        }
)

if ($AddressesElsewhere.Count -gt 0) {
    throw "Het gewenste IP-adres staat al op een andere interface. Geen wijzigingen uitgevoerd."
}

$ExistingAddresses = @(
    Get-NetIPAddress `
        -InterfaceIndex $InternalIndex `
        -AddressFamily IPv4 `
        -PolicyStore ActiveStore `
        -ErrorAction Stop
)

# APIPA is toegestaan als beginstaat op een nieuwe machine.
# Andere afwijkende adressen worden niet automatisch verwijderd.
$UnexpectedAddresses = @(
    $ExistingAddresses |
        Where-Object {
            $_.IPAddress -ne $IPAddress -and
            $_.IPAddress -notlike "169.254.*"
        }
)

if ($UnexpectedAddresses.Count -gt 0) {
    $Found = $UnexpectedAddresses |
        ForEach-Object { "$($_.IPAddress)/$($_.PrefixLength)" }

    throw "Afwijkende interne IP-configuratie: $($Found -join ', '). Geen wijzigingen uitgevoerd."
}

$DesiredAddresses = @(
    $ExistingAddresses |
        Where-Object { $_.IPAddress -eq $IPAddress }
)

if ($DesiredAddresses.Count -gt 1) {
    throw "Het gewenste IP-adres is meermaals gevonden. Geen wijzigingen uitgevoerd."
}

if ($DesiredAddresses.Count -eq 1) {
    $Existing = $DesiredAddresses[0]

    if ($Existing.PrefixLength -ne $PrefixLength) {
        throw "Verkeerde prefix voor ${IPAddress}: $($Existing.PrefixLength), verwacht $PrefixLength."
    }

    if ($Existing.PrefixOrigin.ToString() -ne "Manual") {
        throw "Het gewenste adres is niet statisch ingesteld. Controleer dit handmatig."
    }

    if ($Existing.AddressState.ToString() -in @("Duplicate", "Invalid")) {
        throw "Het bestaande adres heeft een onbruikbare status: $($Existing.AddressState)."
    }

    $IPInterface = Get-NetIPInterface `
        -InterfaceIndex $InternalIndex `
        -AddressFamily IPv4

    if ($IPInterface.Dhcp.ToString() -ne "Disabled") {
        throw "Het statische adres bestaat, maar DHCP staat nog aan. Controleer dit handmatig."
    }

    Write-Output "Het juiste statische IP-adres bestaat al; geen wijziging nodig."
}
else {
    Write-Output "Statisch IP-adres instellen op de interne interface..."

    New-NetIPAddress `
        -InterfaceIndex $InternalIndex `
        -IPAddress $IPAddress `
        -PrefixLength $PrefixLength |
        Out-Null
}

# ------------------------------------------------------------
# 3. Wacht op een bruikbaar adres na duplicate address detection.
# ------------------------------------------------------------

$Deadline = (Get-Date).AddSeconds(60)
$Ready = $false

do {
    $CurrentAddress = Get-NetIPAddress `
        -InterfaceIndex $InternalIndex `
        -AddressFamily IPv4 `
        -PolicyStore ActiveStore |
        Where-Object { $_.IPAddress -eq $IPAddress }

    if ($CurrentAddress) {
        $State = $CurrentAddress.AddressState.ToString()

        if ($State -eq "Duplicate") {
            throw "Dubbel IP-adres gedetecteerd: $IPAddress. Los het adresconflict op."
        }

        if ($State -eq "Preferred") {
            $Ready = $true
            break
        }
    }

    Start-Sleep -Seconds 2
}
while ((Get-Date) -lt $Deadline)

if (-not $Ready) {
    throw "IP-adres $IPAddress is niet binnen 60 seconden bruikbaar geworden."
}

# ------------------------------------------------------------
# 4. Controleer actieve en persistente configuratie.
# ------------------------------------------------------------

$PersistentAddresses = @(
    Get-NetIPAddress `
        -InterfaceIndex $InternalIndex `
        -AddressFamily IPv4 `
        -PolicyStore PersistentStore |
        Where-Object {
            $_.IPAddress -eq $IPAddress -and
            $_.PrefixLength -eq $PrefixLength
        }
)

if ($PersistentAddresses.Count -ne 1) {
    throw "Het gewenste IP-adres is niet eenduidig opgeslagen in PersistentStore."
}

$FinalInterface = Get-NetIPInterface `
    -InterfaceIndex $InternalIndex `
    -AddressFamily IPv4

if ($FinalInterface.Dhcp.ToString() -ne "Disabled") {
    throw "DHCP staat nog aan op de interne serverinterface."
}

Write-Output "Controle actieve configuratie:"

Get-NetIPAddress `
    -InterfaceIndex $InternalIndex `
    -AddressFamily IPv4 `
    -PolicyStore ActiveStore |
    Select-Object InterfaceAlias, InterfaceIndex, IPAddress,
        PrefixLength, PrefixOrigin, AddressState |
    Format-Table -AutoSize |
    Out-String -Width 200 |
    Write-Output

Write-Output "PASS: interne statische IP-configuratie is correct en persistent."
Write-Output "NAT, DNS-serveradressen en DNS-registratie zijn niet gewijzigd."

<#
.SYNOPSIS
    Maakt een domeinbrede GPO voor vertrouwen in de lab-Root-CA.

.DESCRIPTION
    Haalt het publieke CA-certificaat op van server3.
    Leest de Windows-certificaatblob via een tijdelijke certificaatopslag.
    Configureert deze blob als computerbeleid in een aparte GPO.
    Koppelt de GPO aan de domeinroot.

    Uitvoeren nadat de CA op server3 geconfigureerd is.
#>

param(
    [string]$DomainName = "WS26-JD.hogent",

    [string]$CAConfig = "server3.WS26-JD.hogent\WS26-JD-Root-CA",

    [string]$CACommonName = "WS26-JD-Root-CA",

    [string]$GPOName = "WS26 - Vertrouw Root CA"
)

$ErrorActionPreference = "Stop"

if ($env:COMPUTERNAME -ine "server1") {
    throw "Dit script is bedoeld voor server1."
}

Import-Module ActiveDirectory

$Domain = Get-ADDomain -Identity $DomainName -ErrorAction Stop

# ------------------------------------------------------------------
# 1. Group Policy-beheertools installeren.
# ------------------------------------------------------------------

Import-Module ServerManager

if (-not (Get-WindowsFeature -Name GPMC).Installed) {
    $Result = Install-WindowsFeature `
        -Name GPMC `
        -ErrorAction Stop

    if (-not $Result.Success) {
        throw "Installatie van Group Policy-beheertools is mislukt."
    }
}

Import-Module GroupPolicy

# ------------------------------------------------------------------
# 2. Publiek CA-certificaat ophalen.
# ------------------------------------------------------------------

$CertificateDirectory = "C:\LabCertificates"
$CertificatePath = Join-Path $CertificateDirectory "$CACommonName.cer"

New-Item `
    -Path $CertificateDirectory `
    -ItemType Directory `
    -Force |
    Out-Null

Write-Output "Publiek CA-certificaat ophalen van $CAConfig..."

& certutil.exe -f -config "$CAConfig" "-ca.cert" "$CertificatePath"

if ($LASTEXITCODE -ne 0) {
    throw "CA-certificaat ophalen mislukt. Controleer DNS, de CA-service en RPC/firewalltoegang naar server3."
}

$Certificate =
    [System.Security.Cryptography.X509Certificates.X509Certificate2]::new(
        $CertificatePath
    )

if ($Certificate.GetNameInfo(
    [System.Security.Cryptography.X509Certificates.X509NameType]::SimpleName,
    $false
) -ne $CACommonName) {
    throw "Het opgehaalde certificaat heeft niet de verwachte CA-naam."
}

if ($Certificate.Subject -ne $Certificate.Issuer) {
    throw "Het opgehaalde certificaat is niet het verwachte rootcertificaat."
}

if (
    $Certificate.NotAfter -le (Get-Date) -or
    $Certificate.NotBefore -gt (Get-Date)
) {
    throw "Het opgehaalde CA-certificaat is momenteel niet geldig."
}

$Thumbprint = $Certificate.Thumbprint

Write-Output "Opgehaald rootcertificaat: $Thumbprint"

# ------------------------------------------------------------------
# 3. De Windows-certificaatblob uitlezen.
#    Een .cer-bestand is niet rechtstreeks dezelfde data als Blob.
# ------------------------------------------------------------------

$TemporaryStoreName = "WS2Temp_" + [guid]::NewGuid().ToString("N")

$TemporaryStore =
    [System.Security.Cryptography.X509Certificates.X509Store]::new(
        $TemporaryStoreName,
        [System.Security.Cryptography.X509Certificates.StoreLocation]::LocalMachine
    )

$TemporaryRegistryPath =
    "HKLM:\SOFTWARE\Microsoft\SystemCertificates\$TemporaryStoreName"

try {
    $TemporaryStore.Open(
        [System.Security.Cryptography.X509Certificates.OpenFlags]::ReadWrite
    )

    $TemporaryStore.Add($Certificate)

    $BlobPath = "$TemporaryRegistryPath\Certificates\$Thumbprint"

    [byte[]]$CertificateBlob = (
        Get-ItemProperty -Path $BlobPath -Name Blob -ErrorAction Stop
    ).Blob
}
finally {
    $TemporaryStore.Close()

    if (Test-Path $TemporaryRegistryPath) {
        Remove-Item `
            -Path $TemporaryRegistryPath `
            -Recurse `
            -Force `

<#
.SYNOPSIS
    Configureert de primaire DNS-server op server1.

.DESCRIPTION
    Uitvoeren na domeincontroller-promotie en reboot.

    - Controleert DNS-rol en AD-geintegreerde zones.
    - Wacht tot DNS-zones beschikbaar zijn.
    - Schakelt DNS-clientregistratie op NAT uit.
    - Laat DNS luisteren op het Host-Only IP.
    - Ruimt A-records met de huidige NAT-IP-adressen op.
    - Maakt de reverse lookup zone indien nodig aan.
    - Controleert A- en PTR-records onafhankelijk.
    - Configureert gerichte DNS-firewallregels.
    - Configureert NS-records, zone transfers en notify voor server2.
    - Maakt het intranet-A-record aan indien nodig.
    - Controleert bestaande intranetrecords op conflicten.

    Netwerk: 192.168.26.0/24.
#>

param(
    [string]$Server1IP = "192.168.26.10",
    [string]$Server2IP = "192.168.26.20"
)

$ErrorActionPreference = "Stop"

Import-Module ActiveDirectory
Import-Module DnsServer

$NetworkId = "192.168.26.0/24"
$ReverseZone = "26.168.192.in-addr.arpa"

# ------------------------------------------------------------------
# Helper: wacht tot de opgegeven AD-geintegreerde zones geladen zijn.
# ------------------------------------------------------------------
function Wait-PrimaryDnsZones {
    param(
        [Parameter(Mandatory = $true)]
        [string[]]$ZoneNames,

        [int]$TimeoutSeconds = 180
    )

    $Deadline = (Get-Date).AddSeconds($TimeoutSeconds)
    $LastDnsError = "Nog geen resultaat."

    do {
        try {
            $LoadedZones = @(Get-DnsServerZone -ErrorAction Stop)

            $MissingZones = @(
                foreach ($ZoneName in $ZoneNames) {
                    $Found = $LoadedZones | Where-Object {
                        $_.ZoneName -ieq $ZoneName -and
                        $_.ZoneType -eq "Primary" -and
                        $_.IsDsIntegrated
                    }

                    if (-not $Found) {
                        $ZoneName
                    }
                }
            )

            if ($MissingZones.Count -eq 0) {
                Write-Host "DNS gereed: vereiste AD-zones zijn geladen."
                return
            }

            $LastDnsError = "Zones nog niet gereed: $($MissingZones -join ', ')"
        } catch {
            $LastDnsError = $_.Exception.Message
        }

        Write-Host "DNS-zones nog niet gereed; opnieuw proberen over 5 seconden..."
        Start-Sleep -Seconds 5

    } while ((Get-Date) -lt $Deadline)

    throw "DNS niet gereed binnen $TimeoutSeconds seconden. Laatste melding: $LastDnsError"
}

# ------------------------------------------------------------------
# 1. Controleer DNS-rol en Host-Only IP.
# ------------------------------------------------------------------
if (-not (Get-WindowsFeature -Name DNS).Installed) {
    throw "DNS-rol ontbreekt. Voer eerst promote-dc.ps1 uit."
}

$InternalAddresses = @(
    Get-NetIPAddress -AddressFamily IPv4 |
        Where-Object { $_.IPAddress -eq $Server1IP }
)

if ($InternalAddresses.Count -ne 1) {
    throw "Verwacht precies een interface met Host-Only IP $Server1IP."
}

Start-Service DNS

# Bepaal de domeinnaam lokaal, zonder eerst een AD-query uit te voeren.
$ComputerSystem = Get-CimInstance -ClassName Win32_ComputerSystem

if ($ComputerSystem.DomainRole -notin @(4, 5)) {
    throw "Dit script moet op de domeincontroller worden uitgevoerd."
}

$ForwardZone = $ComputerSystem.Domain
$MsdcsZone = "_msdcs.$ForwardZone"
$RequiredAdZones = @($ForwardZone, $MsdcsZone)

Wait-PrimaryDnsZones -ZoneNames $RequiredAdZones

# Controleer daarna ook de AD-domeinnaam.
$Domain = Get-ADDomain -Server $env:COMPUTERNAME

if ($Domain.DNSRoot -ine $ForwardZone) {
    throw "AD-domeinnaam komt niet overeen met de lokale domeinconfiguratie."
}

Write-Host "AD-forward zone aanwezig: $ForwardZone"

# ------------------------------------------------------------------
# 2. Identificeer NAT en schakel clientregistratie uit.
# ------------------------------------------------------------------
$NatAdapters = @(
    Get-NetAdapter |
        Where-Object { $_.Status -eq "Up" } |
        Where-Object {
            $Config = Get-NetIPConfiguration -InterfaceIndex $_.ifIndex
            $null -ne $Config.IPv4DefaultGateway
        }
)

if ($NatAdapters.Count -ne 1) {
    throw "Verwacht precies een actieve NAT-interface met default gateway."
}

$NatAdapter = $NatAdapters[0]

$NatIPs = @(
    Get-NetIPAddress -InterfaceIndex $NatAdapter.ifIndex `
        -AddressFamily IPv4 |
        Select-Object -ExpandProperty IPAddress
)

Set-DnsClient -InterfaceIndex $NatAdapter.ifIndex `
    -RegisterThisConnectionsAddress $false `
    -UseSuffixWhenRegistering $false

Write-Host "DNS-clientregistratie uit op NAT: $($NatAdapter.Name)"

# ------------------------------------------------------------------
# 3. Laat DNS luisteren op het Host-Only IP.
# ------------------------------------------------------------------
$DnsCmd = "$env:SystemRoot\System32\dnscmd.exe"

& $DnsCmd localhost /ResetListenAddresses $Server1IP

if ($LASTEXITCODE -ne 0) {
    throw "Instellen van het DNS-luisteradres is mislukt."
}

Restart-Service DNS

Wait-PrimaryDnsZones -ZoneNames $RequiredAdZones

# ------------------------------------------------------------------
# 4. Ruim huidige NAT-A-records op in primaire forward zones.
# ------------------------------------------------------------------
$PrimaryForwardZones = @(
    Get-DnsServerZone | Where-Object {
        $_.ZoneType -eq "Primary" -and
        -not $_.IsReverseLookupZone
    }
)

foreach ($Zone in $PrimaryForwardZones) {
    $Records = @(Get-DnsServerResourceRecord -ZoneName $Zone.ZoneName)

    foreach ($Record in $Records) {
        if ($Record.RecordType -eq "A" -and
            $Record.RecordData.IPv4Address.IPAddressToString -in $NatIPs) {

            Remove-DnsServerResourceRecord -ZoneName $Zone.ZoneName `
                -InputObject $Record -Force

            Write-Host "NAT-A-record verwijderd: $($Record.HostName) in $($Zone.ZoneName)"
        }
    }
}

# ------------------------------------------------------------------
# 5. Maak de reverse zone aan indien nodig.
# ------------------------------------------------------------------
$ExistingReverse = Get-DnsServerZone |
    Where-Object { $_.ZoneName -ieq $ReverseZone }

if (-not $ExistingReverse) {
    Add-DnsServerPrimaryZone -NetworkId $NetworkId `
        -ReplicationScope Domain `
        -DynamicUpdate Secure

    Write-Host "Reverse zone aangemaakt: $ReverseZone"

} elseif ($ExistingReverse.ZoneType -ne "Primary" -or
          -not $ExistingReverse.IsDsIntegrated) {

    throw "Bestaande reverse zone is niet AD-geintegreerd en Primary."
} else {
    Write-Host "Reverse zone bestaat reeds: $ReverseZone"
}

# ------------------------------------------------------------------
# 6. Controleer A- en PTR-records onafhankelijk.
# ------------------------------------------------------------------
$Servers = @(
    @{ Name = "server1"; IP = $Server1IP }
    @{ Name = "server2"; IP = $Server2IP }
    @{ Name = "server3"; IP = "192.168.26.30" }
)

foreach ($Server in $Servers) {
    $Name = $Server.Name
    $IP = $Server.IP
    $Fqdn = "$Name.$ForwardZone."
    $PtrName = ($IP -split "\.")[-1]

    # A-records controleren.
    $ARecords = @(
        Get-DnsServerResourceRecord -ZoneName $ForwardZone |
            Where-Object {
                $_.HostName -ieq $Name -and
                $_.RecordType -eq "A"
            }
    )

    foreach ($Record in $ARecords) {
        if ($Record.RecordData.IPv4Address.IPAddressToString -ne $IP) {
            Remove-DnsServerResourceRecord -ZoneName $ForwardZone `
                -InputObject $Record -Force

            Write-Host "Verkeerd A-record verwijderd voor $Name"
        }
    }

    $CorrectA = @(
        $ARecords | Where-Object {
            $_.RecordData.IPv4Address.IPAddressToString -eq $IP
        }
    )

    if ($CorrectA.Count -eq 0) {
        Add-DnsServerResourceRecordA -ZoneName $ForwardZone `
            -Name $Name `
            -IPv4Address $IP

        Write-Host "A-record aangemaakt: $Name -> $IP"
    } else {
        Write-Host "A-record correct: $Name -> $IP"
    }

    # PTR-records afzonderlijk controleren.
    $PtrRecords = @(
        Get-DnsServerResourceRecord -ZoneName $ReverseZone |
            Where-Object {
                $_.HostName -eq $PtrName -and
                $_.RecordType -eq "PTR"
            }
    )

    foreach ($Record in $PtrRecords) {
        if ($Record.RecordData.PtrDomainName.TrimEnd(".") -ine
            $Fqdn.TrimEnd(".")) {

            Remove-DnsServerResourceRecord -ZoneName $ReverseZone `
                -InputObject $Record -Force

            Write-Host "Verkeerd PTR-record verwijderd voor $IP"
        }
    }

    $CorrectPtr = @(
        $PtrRecords | Where-Object {
            $_.RecordData.PtrDomainName.TrimEnd(".") -ieq
                $Fqdn.TrimEnd(".")
        }
    )

    if ($CorrectPtr.Count -eq 0) {
        Add-DnsServerResourceRecordPtr -ZoneName $ReverseZone `
            -Name $PtrName `
            -PtrDomainName $Fqdn

        Write-Host "PTR-record aangemaakt: $IP -> $Fqdn"
    } else {
        Write-Host "PTR-record correct: $IP -> $Fqdn"
    }
}

# ------------------------------------------------------------------
# 7. Maak gerichte DNS-firewallregels aan of herstel ze.
# ------------------------------------------------------------------
foreach ($Protocol in @("TCP", "UDP")) {
    $RuleName = "WS2-DNS-$Protocol-HostOnly"
    $RuleDisplayName = "WS2 DNS $Protocol via Host-Only"

    # Alleen parameters die bij New en Set dezelfde functie hebben.
    $RuleSettings = @{
        Direction     = "Inbound"
        Action        = "Allow"
        Enabled       = "True"
        Protocol      = $Protocol
        LocalPort     = 53
        LocalAddress  = $Server1IP
        RemoteAddress = $NetworkId
        Profile       = "Any"
    }

    $ExistingRule = Get-NetFirewallRule -Name $RuleName `
        -ErrorAction SilentlyContinue

    if ($ExistingRule) {
        Set-NetFirewallRule -Name $RuleName `
            -NewDisplayName $RuleDisplayName `
            @RuleSettings

        Write-Host "Firewallregel gecontroleerd: $RuleName"
    } else {
        New-NetFirewallRule -Name $RuleName `
            -DisplayName $RuleDisplayName `
            @RuleSettings |
            Out-Null

        Write-Host "Firewallregel aangemaakt: $RuleName"
    }
}

# ------------------------------------------------------------------
# 8. Configureer server2 als naamserver en transferdoel.
# ------------------------------------------------------------------
$Server2Fqdn = "server2.$ForwardZone."

$TransferZones = @(
    $ForwardZone
    $ReverseZone
    $MsdcsZone
)

foreach ($ZoneName in $TransferZones) {
    $ExistingNS = Get-DnsServerResourceRecord -ZoneName $ZoneName |
        Where-Object {
            $_.RecordType -eq "NS" -and
            $_.HostName -eq "@" -and
            $_.RecordData.NameServer.TrimEnd(".") -ieq
                $Server2Fqdn.TrimEnd(".")
        }

    if (-not $ExistingNS) {
        Add-DnsServerResourceRecord -ZoneName $ZoneName `
            -NS `
            -Name "@" `
            -NameServer $Server2Fqdn

        Write-Host "NS-record toegevoegd: server2 in $ZoneName"
    } else {
        Write-Host "NS-record server2 aanwezig in $ZoneName"
    }

    Set-DnsServerPrimaryZone -Name $ZoneName `
        -SecureSecondaries TransferToSecureServers `
        -SecondaryServers $Server2IP `
        -Notify NotifyServers `
        -NotifyServers $Server2IP

    Write-Host "Zone transfer en notify ingesteld: $ZoneName -> $Server2IP"
}

# ------------------------------------------------------------------
# 9. Maak het intranet-A-record aan of controleer het bestaande record.
# ------------------------------------------------------------------
$IntranetName = "intranet"
$IntranetFqdn = "$IntranetName.$ForwardZone"

$ExistingIntranetRecords = @(
    Get-DnsServerResourceRecord -ZoneName $ForwardZone `
        -ErrorAction Stop |
        Where-Object { $_.HostName -ieq $IntranetName }
)

$ExistingIntranetARecords = @(
    $ExistingIntranetRecords |
        Where-Object { $_.RecordType -eq "A" }
)

$ConflictingIntranetRecords = @(
    $ExistingIntranetRecords |
        Where-Object { $_.RecordType -in @("CNAME", "AAAA") }
)

if ($ConflictingIntranetRecords.Count -gt 0) {
    throw "Er bestaat al een CNAME- of AAAA-record voor $IntranetFqdn. Controleer dit eerst."
}

if ($ExistingIntranetARecords.Count -eq 0) {
    Add-DnsServerResourceRecordA -ZoneName $ForwardZone `
        -Name $IntranetName `
        -IPv4Address $Server1IP `
        -ErrorAction Stop

    Write-Host "Intranetrecord aangemaakt: $IntranetFqdn -> $Server1IP"
} elseif (
    $ExistingIntranetARecords.Count -ne 1 -or
    $ExistingIntranetARecords[0].RecordData.IPv4Address.IPAddressToString -ne $Server1IP
) {
    throw "Het bestaande A-record voor $IntranetFqdn wijkt af van $Server1IP. Controleer dit eerst."
} else {
    Write-Host "Intranetrecord correct: $IntranetFqdn -> $Server1IP"
}

Write-Host "`nPrimaire DNS-configuratie voltooid." -ForegroundColor Green

#Requires -RunAsAdministrator

<#
.SYNOPSIS
    Geeft Administrator en SERVER3$ Read- en Enroll-rechten
    op de bestaande WebServer-template.

.DESCRIPTION
    Gebruikt expliciete domeincredentials.
    Wijzigt uitsluitend de DACL.
    Behoudt bestaande rechten en de bestaande eigenaar.
#>

param(
    [string]$DomainAdminUser = "WS26-JD\Administrator",

    [Parameter(Mandatory = $true)]
    [string]$DomainAdminPassword
)

$ErrorActionPreference = "Stop"

if ($env:COMPUTERNAME -ine "server1") {
    throw "Dit script is bedoeld voor server1."
}

Import-Module ActiveDirectory

$SecurePassword = ConvertTo-SecureString `
    -String $DomainAdminPassword `
    -AsPlainText `
    -Force

$Credential = [System.Management.Automation.PSCredential]::new(
    $DomainAdminUser,
    $SecurePassword
)

$DirectoryServer = "server1.WS26-JD.hogent"

$ADParameters = @{
    Server      = $DirectoryServer
    Credential  = $Credential
    ErrorAction = "Stop"
}

$Domain = Get-ADDomain @ADParameters

if ($Domain.DNSRoot -ine "WS26-JD.hogent") {
    throw "Onverwacht domein: $($Domain.DNSRoot)"
}

$ConfigurationDN = (
    Get-ADRootDSE @ADParameters
).configurationNamingContext

$TemplateDN =
    "CN=WebServer,CN=Certificate Templates," +
    "CN=Public Key Services,CN=Services,$ConfigurationDN"

$Administrator = Get-ADUser `
    -Identity "$($Domain.DomainSID.Value)-500" `
    @ADParameters

$Server3 = Get-ADComputer `
    -Identity "server3" `
    @ADParameters

$Entry = [System.DirectoryServices.DirectoryEntry]::new(
    "LDAP://$DirectoryServer/$TemplateDN",
    $DomainAdminUser,
    $DomainAdminPassword,
    [System.DirectoryServices.AuthenticationTypes]::Secure
)

try {
    # Alleen de DACL lezen en schrijven.
    $Entry.PSBase.Options.SecurityMasks =
        [System.DirectoryServices.SecurityMasks]::Dacl

    $Entry.PSBase.RefreshCache(@("nTSecurityDescriptor"))

    $Acl = $Entry.PSBase.ObjectSecurity

    $EnrollGuid = [guid]"0e10c968-78fb-11d2-90d4-00c04f79dc55"

    foreach ($Account in @($Administrator, $Server3)) {
        $Sid = [System.Security.Principal.SecurityIdentifier]$Account.SID

        $ReadRule =
            [System.DirectoryServices.ActiveDirectoryAccessRule]::new(
                $Sid,
                [System.DirectoryServices.ActiveDirectoryRights]::GenericRead,
                [System.Security.AccessControl.AccessControlType]::Allow
            )

        $EnrollRule =
            [System.DirectoryServices.ActiveDirectoryAccessRule]::new(
                $Sid,
                [System.DirectoryServices.ActiveDirectoryRights]::ExtendedRight,
                [System.Security.AccessControl.AccessControlType]::Allow,
                $EnrollGuid
            )

        $Acl.AddAccessRule($ReadRule)
        $Acl.AddAccessRule($EnrollRule)
    }

    $Entry.PSBase.ObjectSecurity = $Acl

        # Alleen de eerder toegevoegde brede Enroll-regel opruimen.
    # Andere rechten, waaronder GenericRead, blijven behouden.
    $AuthenticatedUsersSid = "S-1-5-11"

    $BroadEnrollRules = @(
        $Acl.GetAccessRules(
            $true,
            $false,
            [System.Security.Principal.SecurityIdentifier]
        ) |
            Where-Object {
                $_.IdentityReference.Value -eq $AuthenticatedUsersSid -and
                $_.AccessControlType -eq
                    [System.Security.AccessControl.AccessControlType]::Allow -and
                $_.ObjectType -eq $EnrollGuid -and
                $_.ActiveDirectoryRights -eq
                    [System.DirectoryServices.ActiveDirectoryRights]::ExtendedRight
            }
    )

    foreach ($Rule in $BroadEnrollRules) {
        $Acl.RemoveAccessRuleSpecific($Rule)
    }

    Write-Output (
        "Brede expliciete Enroll-regels verwijderd voor Authenticated Users: {0}." -f
        $BroadEnrollRules.Count
    )

    $Entry.PSBase.CommitChanges()

    # Opnieuw ophalen na het opslaan.
    $Entry.PSBase.RefreshCache(@("nTSecurityDescriptor"))

        # Controleer de expliciete allow-regels die dit script beheert.
    $StoredRules = @(
        $Entry.PSBase.ObjectSecurity.GetAccessRules(
            $true,
            $false,
            [System.Security.Principal.SecurityIdentifier]
        )
    )

        $RemainingBroadEnroll = @(
        $StoredRules |
            Where-Object {
                $_.IdentityReference.Value -eq $AuthenticatedUsersSid -and
                $_.AccessControlType -eq
                    [System.Security.AccessControl.AccessControlType]::Allow -and
                $_.ObjectType -eq $EnrollGuid -and
                (
                    $_.ActiveDirectoryRights -band
                    [System.DirectoryServices.ActiveDirectoryRights]::ExtendedRight
                ) -ne 0
            }
    )

    if ($RemainingBroadEnroll.Count -gt 0) {
        throw "Er staat nog een expliciete Enroll-regel voor Authenticated Users. Controleer de ACL handmatig."
    }

    $AuthenticatedUsersRead = @(
        $StoredRules |
            Where-Object {
                $_.IdentityReference.Value -eq $AuthenticatedUsersSid -and
                $_.AccessControlType -eq
                    [System.Security.AccessControl.AccessControlType]::Allow -and
                $_.ObjectType -eq [guid]::Empty -and
                (
                    $_.ActiveDirectoryRights -band
                    [System.DirectoryServices.ActiveDirectoryRights]::GenericRead
                ) -eq
                    [System.DirectoryServices.ActiveDirectoryRights]::GenericRead
            }
    )

    if ($AuthenticatedUsersRead.Count -eq 0) {
        throw "Het verwachte expliciete Read-recht voor Authenticated Users ontbreekt."
    }

    Write-Output "PASS: expliciet Enroll voor Authenticated Users afwezig; Read behouden."

    $ReadMask = [System.DirectoryServices.ActiveDirectoryRights]::GenericRead
    $EnrollMask = [System.DirectoryServices.ActiveDirectoryRights]::ExtendedRight

    foreach ($Account in @($Administrator, $Server3)) {
        $SidValue = $Account.SID.Value

        $AccountAllowRules = @(
            $StoredRules |
                Where-Object {
                    $_.IdentityReference.Value -eq $SidValue -and
                    $_.AccessControlType -eq
                        [System.Security.AccessControl.AccessControlType]::Allow
                }
        )

        $ReadRules = @(
            $AccountAllowRules |
                Where-Object {
                    $_.ObjectType -eq [guid]::Empty -and
                    ($_.ActiveDirectoryRights -band $ReadMask) -eq $ReadMask
                }
        )

        $EnrollRules = @(
            $AccountAllowRules |
                Where-Object {
                    $_.ObjectType -eq $EnrollGuid -and
                    ($_.ActiveDirectoryRights -band $EnrollMask) -eq $EnrollMask
                }
        )

        if ($ReadRules.Count -eq 0) {
            throw "Controle mislukt: expliciet Read-recht ontbreekt voor $($Account.SamAccountName)."
        }

        if ($EnrollRules.Count -eq 0) {
            throw "Controle mislukt: expliciet Enroll-recht ontbreekt voor $($Account.SamAccountName)."
        }

        Write-Output (
            "PASS: expliciete Read- en Enroll-regels opgeslagen voor {0}." -f
            $Account.SamAccountName
        )
    }

    Write-Output "Template-DACL opgeslagen via $DomainAdminUser."
    Write-Output "Controle expliciete Enroll-regels:"

    $Entry.PSBase.ObjectSecurity.GetAccessRules(
        $true,
        $false,
        [System.Security.Principal.SecurityIdentifier]
    ) |
        Where-Object {
            $_.ObjectType -eq $EnrollGuid -and
            $_.IdentityReference.Value -in @(
                $Administrator.SID.Value,
                $Server3.SID.Value
            )
        } |
        Select-Object IdentityReference, ActiveDirectoryRights,
            AccessControlType, ObjectType |
        Format-List |
        Out-String -Width 200 |
        Write-Output
}
finally {
    $Entry.PSBase.Dispose()
}

$DomainDN = (Get-ADDomain).DistinguishedName

# ---------------------------------------------------------------------------

$ErrorActionPreference = "Stop"

}

    $Now = Get-Date

    $RootCertificate = Get-ChildItem Cert:\LocalMachine\Root |
        Where-Object {
            $_.Subject -like "*$CACommonName*" -and
            $_.NotBefore -le $Now -and

        break
    }

    Write-Output "Rootcertificaat nog niet ontvangen; opnieuw proberen over 15 seconden..."
    Start-Sleep -Seconds 15
}

if (-not $RootCertificate) {
    throw "Rootcertificaat '$CACommonName' is niet binnen drie minuten na de beleidsvernieuwing gevonden."
}

Write-Output "Rootcertificaat aanwezig in Trusted Root:"

$RootCertificate |
    Format-List Subject, Thumbprint, NotAfter |
    Out-String -Width 200 |
    Write-Output

$ErrorActionPreference = "Stop"

$HttpUrl = "http://$WebFqdn/CertSrv/"
$ExpectedDestination = "https://$WebFqdn/certsrv/Default.asp"

}

Write-Output "HTTP-ingang: $HttpUrl"

# 1. HTTP-aanvraag zonder credentials.
#    Automatische redirects uitschakelen zodat we de redirect expliciet controleren.
$Request = [System.Net.HttpWebRequest]::Create($HttpUrl)
$Request.AllowAutoRedirect = $false
$Request.Timeout = 30000

$RedirectResponse = $Request.GetResponse()

try {
    $RedirectStatus = [int]$RedirectResponse.StatusCode
    $RedirectDestination = $RedirectResponse.Headers["Location"]
}
finally {
    $RedirectResponse.Close()
}

if (
    $RedirectStatus -ne 302 -or
    $RedirectDestination -ne $ExpectedDestination
) {
    throw "Onverwachte redirect: HTTP $RedirectStatus naar '$RedirectDestination'."
}

Write-Output "HTTP-redirect: 302 naar $RedirectDestination"

# 2. Gecontroleerde HTTPS-bestemming met domeincredentials ophalen.
$SecurePassword = ConvertTo-SecureString `
    $AdminPassword `
    -AsPlainText `
    -Force

$Credential = [System.Management.Automation.PSCredential]::new(
    "$Domain\$AdminUser",
    $SecurePassword
)

$Page = Invoke-WebRequest `
    -Uri $RedirectDestination `
    -Credential $Credential `
    -UseBasicParsing `
    -TimeoutSec 30 `
    -ErrorAction Stop

if ($Page.StatusCode -ne 200) {
    throw "HTTPS-pagina retourneert HTTP $($Page.StatusCode) in plaats van 200."
}

$Title = [regex]::Match(

).Groups[1].Value.Trim()

    throw "De HTTPS-pagina bevat niet de verwachte Certificate Services-titel."

Write-Output "HTTPS-pagina: HTTP 200"

<#
.SYNOPSIS
    Configureert server2 als secundaire DNS-server.

.DESCRIPTION
    Uitvoeren nadat het Host-Only IP is ingesteld.

    - Installeert de DNS-rol.
    - Schakelt DNS-registratie op de NAT-interface uit.
    - Laat DNS luisteren op het Host-Only IP.
    - Voegt gerichte DNS-firewallregels toe.
    - Configureert secundaire zones met server1 als master.
    - Vraagt een volledige zone transfer aan.

    Vereist:
    Server1 moet zone transfers naar 192.168.26.20 toestaan.
#>

param(
    [string]$PrimaryIP = "192.168.26.10",
    [string]$SecondaryIP = "192.168.26.20",
    [string]$DomainName = "WS26-JD.hogent"
)

$ErrorActionPreference = "Stop"

$Zones = @(
    $DomainName
    "26.168.192.in-addr.arpa"
    "_msdcs.$DomainName"
)

# ------------------------------------------------------------------
# 1. Controleer het Host-Only IP.
# ------------------------------------------------------------------

$InternalAddresses = @(
    Get-NetIPAddress -AddressFamily IPv4 |
        Where-Object { $_.IPAddress -eq $SecondaryIP }
)

if ($InternalAddresses.Count -ne 1) {
    throw "Verwacht precies een interface met Host-Only IP $SecondaryIP."
}

$InternalInterfaceIndex = $InternalAddresses[0].InterfaceIndex

# ------------------------------------------------------------------
# 2. Installeer de DNS-rol, niet AD DS.
# ------------------------------------------------------------------

if (-not (Get-WindowsFeature -Name DNS).Installed) {
    Write-Host "DNS-rol installeren..."

    $Install = Install-WindowsFeature -Name DNS -IncludeManagementTools

    if (-not $Install.Success) {
        throw "Installatie van de DNS-rol is mislukt."
    }

    Write-Host "DNS-rol geinstalleerd."
} else {
    Write-Host "DNS-rol is al aanwezig."
}

Import-Module DnsServer
Start-Service DNS

# ------------------------------------------------------------------
# 3. Schakel DNS-registratie op de NAT-interface uit.
# ------------------------------------------------------------------

$NatAdapters = @(
    Get-NetAdapter | Where-Object {
        $Config = Get-NetIPConfiguration -InterfaceIndex $_.ifIndex
        $null -ne $Config.IPv4DefaultGateway
    }
)

if ($NatAdapters.Count -ne 1) {
    throw "Verwacht precies een NAT-interface met default gateway."
}

Set-DnsClient -InterfaceIndex $NatAdapters[0].ifIndex `
    -RegisterThisConnectionsAddress $false

Write-Host "DNS-registratie uitgeschakeld op NAT-interface: $($NatAdapters[0].Name)"

# Gebruik server1 voor de eigen interne naamresolutie.
Set-DnsClientServerAddress -InterfaceIndex $InternalInterfaceIndex `
    -ServerAddresses $PrimaryIP

# ------------------------------------------------------------------
# 4. Laat de DNS-server luisteren op het Host-Only IP.
# ------------------------------------------------------------------

$DnsCmd = "$env:SystemRoot\System32\dnscmd.exe"

& $DnsCmd localhost /ResetListenAddresses $SecondaryIP

if ($LASTEXITCODE -ne 0) {
    throw "Instellen van het DNS-luisteradres is mislukt."
}

Restart-Service DNS

# Wacht op de DNS-beheerinterface, niet alleen op status Running.
$Deadline = (Get-Date).AddSeconds(120)
$Ready = $false
$LastDnsError = $null

do {
    try {
        $ExistingZones = @(Get-DnsServerZone -ErrorAction Stop)
        $Ready = $true
        break
    } catch {
        $LastDnsError = $_.Exception.Message
        Write-Host "DNS nog niet gereed; opnieuw proberen over 5 seconden..."
        Start-Sleep -Seconds 5
    }
} while ((Get-Date) -lt $Deadline)

if (-not $Ready) {
    throw "DNS niet gereed binnen 120 seconden. Laatste fout: $LastDnsError"
}

# ------------------------------------------------------------------
# 5. Voeg gerichte inkomende DNS-firewallregels toe.
# ------------------------------------------------------------------

foreach ($Protocol in @("TCP", "UDP")) {
    $RuleName = "WS2-DNS-$Protocol-HostOnly"

    $ExistingRule = Get-NetFirewallRule -Name $RuleName `
        -ErrorAction SilentlyContinue

    if (-not $ExistingRule) {
        New-NetFirewallRule -Name $RuleName `
            -DisplayName "WS2 DNS $Protocol via Host-Only" `
            -Direction Inbound `
            -Action Allow `
            -Protocol $Protocol `
            -LocalPort 53 `
            -LocalAddress $SecondaryIP `
            -RemoteAddress "192.168.26.0/24" `
            -Profile Any | Out-Null

        Write-Host "Firewallregel toegevoegd: $RuleName"
    } else {
        Write-Host "Firewallregel bestaat al: $RuleName"
    }
}

# ------------------------------------------------------------------
# 6. Controleer TCP-bereikbaarheid van de primaire DNS-server.
# ------------------------------------------------------------------

Write-Host "Verbinding met primaire DNS-server controleren..."

$PrimaryReachable = Test-NetConnection -ComputerName $PrimaryIP `
    -Port 53 -InformationLevel Quiet -WarningAction SilentlyContinue

if (-not $PrimaryReachable) {
    throw "Server1 ($PrimaryIP) is niet bereikbaar op TCP-poort 53. Controleer server1 en de firewall."
}

# ------------------------------------------------------------------
# 7. Configureer de secundaire zones.
# ------------------------------------------------------------------

foreach ($Zone in $Zones) {
    $Existing = $ExistingZones |
        Where-Object { $_.ZoneName -ieq $Zone }

    if (-not $Existing) {
        Add-DnsServerSecondaryZone -Name $Zone `
            -ZoneFile "$Zone.dns" `
            -MasterServers $PrimaryIP

        Write-Host "Secundaire zone aangemaakt: $Zone"
    } elseif ($Existing.ZoneType -ne "Secondary") {
        throw "Zone $Zone bestaat maar is niet Secondary. Niet automatisch overschreven."
    } else {
        Set-DnsServerSecondaryZone -Name $Zone `
            -MasterServers $PrimaryIP

        Write-Host "Master gecontroleerd voor bestaande secundaire zone: $Zone"
    }

    Start-DnsServerZoneTransfer -Name $Zone -FullTransfer

    Write-Host "Volledige zone transfer aangevraagd: $Zone"
}

Write-Host "`nConfiguratie van secundaire DNS voltooid." -ForegroundColor Green
Write-Host "Controleer hierna of de zones en records daadwerkelijk geladen zijn."

#Requires -RunAsAdministrator

<#
.SYNOPSIS
    Installeert en configureert de Enterprise Root CA op server3.

.DESCRIPTION
    Controleert het domeinlidmaatschap.
    Installeert indien nodig de CA-rol.
    Configureert de CA als deze nog niet geconfigureerd is.
    Exporteert het publieke rootcertificaat voor de latere GPO.

    Bestaande CA-sleutels en databases worden niet overschreven.
#>

param(
    [string]$DomainName = "WS26-JD.hogent",

    [string]$DomainAdminUser = "WS26-JD\Administrator",

    [string]$DomainAdminPassword,

    [string]$CACommonName = "WS26-JD-Root-CA"
)

$ErrorActionPreference = "Stop"

Import-Module ServerManager

# ------------------------------------------------------------------
# 1. Server en domein controleren.
# ------------------------------------------------------------------

if ($env:COMPUTERNAME -ine "server3") {
    throw "Dit script is bedoeld voor server3, niet voor $env:COMPUTERNAME."
}

$Computer = Get-CimInstance -ClassName Win32_ComputerSystem

if (
    -not $Computer.PartOfDomain -or
    $Computer.Domain -ine $DomainName
) {
    throw "Server3 moet eerst lid zijn van $DomainName en daarna herstart zijn."
}

# ------------------------------------------------------------------
# 2. CA-rol installeren.
# ------------------------------------------------------------------

if (-not (Get-WindowsFeature -Name ADCS-Cert-Authority).Installed) {
    Write-Output "Certification Authority-rol installeren..."

    $Result = Install-WindowsFeature `
        -Name ADCS-Cert-Authority `
        -IncludeManagementTools `
        -ErrorAction Stop

    if (-not $Result.Success) {
        throw "Installatie van de CA-rol is mislukt."
    }

    if ($Result.RestartNeeded -eq "Yes") {
        throw "Herstart server3 en voer deze provisioner daarna opnieuw uit."
    }
}
else {
    Write-Output "Certification Authority-rol is al geinstalleerd."
}

Import-Module ADCSDeployment

# ------------------------------------------------------------------
# 3. Bestaande CA-configuratie controleren.
# ------------------------------------------------------------------

$CARegistryPath =
    "HKLM:\SYSTEM\CurrentControlSet\Services\CertSvc\Configuration"

$ActiveCA = $null

if (Test-Path $CARegistryPath) {
    $ActiveCA = (
        Get-ItemProperty -Path $CARegistryPath -ErrorAction Stop
    ).Active
}

if ($ActiveCA) {
    if ($ActiveCA -ne $CACommonName) {
        throw "Er bestaat al een andere CA: $ActiveCA. Deze wordt niet overschreven."
    }

    $ExistingCA = Get-ItemProperty `
        -Path "$CARegistryPath\$ActiveCA" `
        -ErrorAction Stop

    # CAType 0 = Enterprise Root CA.
    if ($ExistingCA.CAType -ne 0) {
        throw "De bestaande CA is geen Enterprise Root CA. Controleer de configuratie."
    }

    Write-Output "Enterprise Root CA $CACommonName is al geconfigureerd."
}
else {
    if ([string]::IsNullOrWhiteSpace($DomainAdminPassword)) {
        throw "Geen domein-Administratorwachtwoord ontvangen vanuit Vagrant."
    }

    $SecurePassword = ConvertTo-SecureString `
        -String $DomainAdminPassword `
        -AsPlainText `
        -Force

    $Credential = [System.Management.Automation.PSCredential]::new(
        $DomainAdminUser,
        $SecurePassword
    )

    $DistinguishedNameSuffix = (
        $DomainName.Split(".") |
            ForEach-Object { "DC=$_" }
    ) -join ","

    Write-Output "Enterprise Root CA $CACommonName configureren..."

    $CAParameters = @{
        CAType                    = "EnterpriseRootCA"
        CACommonName              = $CACommonName
        CADistinguishedNameSuffix = $DistinguishedNameSuffix
        CryptoProviderName        = "RSA#Microsoft Software Key Storage Provider"
        KeyLength                 = 2048
        HashAlgorithmName         = "SHA256"
        ValidityPeriod            = "Years"
        ValidityPeriodUnits       = 5
        Credential                = $Credential
        Force                     = $true

    if (
        $Scope.StartRange.ToString() -ne $StartRange -or
        $Scope.EndRange.ToString() -ne $EndRange -or
        $Scope.SubnetMask.ToString() -ne $SubnetMask
    ) {
        throw "Scope $ScopeId bestaat met een afwijkend bereik of subnetmasker. Controleer de bestaande configuratie."
    }

    Write-Output "DHCP-scope bestaat al met het juiste bereik."

    Get-DhcpServerv4ExclusionRange `
        -ScopeId $ScopeId `
        -ErrorAction Stop
)

$MatchingExclusion = $Exclusions | Where-Object {
    $_.StartRange.ToString() -eq $ExclusionStart -and
    $_.EndRange.ToString() -eq $ExclusionEnd
}

if (-not $MatchingExclusion) {
    Write-Output "Exclusion $ExclusionStart - $ExclusionEnd toevoegen..."

    Add-DhcpServerv4ExclusionRange `
        -ScopeId $ScopeId `
        -StartRange $ExclusionStart `
        -EndRange $ExclusionEnd `
        -ErrorAction Stop
}
else {
    Write-Output "De vereiste exclusion bestaat al."
}

Write-Output "DHCP-scope activeren..."

Set-DhcpServerv4Scope `
    -ScopeId $ScopeId `
    -State Active `
    -ErrorAction Stop

Write-Output "Controle DHCP-scope:"

Get-DhcpServerv4Scope -ScopeId $ScopeId -ErrorAction Stop |

Write-Output "Controle exclusions:"

Get-DhcpServerv4ExclusionRange -ScopeId $ScopeId -ErrorAction Stop |
    Format-List ScopeId, StartRange, EndRange |
    Out-String -Width 200 |
    Write-Output

# Bestaande aanvullende controles behouden.
Get-DhcpServerv4Scope -ScopeId $ScopeId |
    Select-Object ScopeId, Name, StartRange, EndRange, SubnetMask, State

Write-Output "Controle exclusions:"

Get-DhcpServerv4ExclusionRange -ScopeId $ScopeId |
    Select-Object ScopeId, StartRange, EndRange

# ------------------------------------------------------------------
# DHCP-opties voor het interne Host-Only-netwerk.

Write-Output "DHCP-opties instellen: DNS-servers en DNS-domeinnaam..."

Set-DhcpServerv4OptionValue `

Write-Output "Geen routeroptie instellen: Host-Only is enkel intern."

Write-Output "DNS-registratie door DHCP uitschakelen..."

$exitCode = 0

try {

        Get-DhcpServerInDC -ErrorAction Stop |

                $_.DnsName -ieq $dnsName -and
                $_.IPAddress.ToString() -eq $ipAddress

#Requires -RunAsAdministrator

<#
.SYNOPSIS
    Voegt server3 toe aan het domein.

.DESCRIPTION
    Controleert eerst het bestaande domeinlidmaatschap.
    Voegt server3 indien nodig toe aan de Servers-OU.
    Vagrant verzorgt daarna de herstart.
#>

param(
    [string]$DomainName = "WS26-JD.hogent",

    [string]$OUPath = "OU=Servers,DC=WS26-JD,DC=hogent",

    [string]$DomainAdminUser = "WS26-JD\Administrator",

    [string]$DomainAdminPassword
)

$ErrorActionPreference = "Stop"

if ($env:COMPUTERNAME -ine "server3") {
    throw "Dit script is bedoeld voor server3, niet voor $env:COMPUTERNAME."
}

$Computer = Get-CimInstance -ClassName Win32_ComputerSystem

if ($Computer.PartOfDomain) {
    if ($Computer.Domain -ine $DomainName) {
        throw "Server3 is al lid van een ander domein: $($Computer.Domain)."
    }

    Write-Output "Server3 is al lid van $DomainName. Domeinjoin overslaan."
    return
}

if ([string]::IsNullOrWhiteSpace($DomainAdminPassword)) {
    throw "Geen domeinwachtwoord opgegeven. Stel WS2_DOMAIN_ADMIN_PASSWORD in op de host."
}

$SecurePassword = ConvertTo-SecureString `
    -String $DomainAdminPassword `
    -AsPlainText `
    -Force

$Credential = [System.Management.Automation.PSCredential]::new(
    $DomainAdminUser,
    $SecurePassword
)

# Interne interface herkennen aan het verwachte server3-adres.
$InternalAddresses = @(
    Get-NetIPAddress -AddressFamily IPv4 -PolicyStore ActiveStore |
        Where-Object { $_.IPAddress -eq "192.168.26.30" }
)

if ($InternalAddresses.Count -ne 1) {
    throw "Verwacht precies een interface met IP-adres 192.168.26.30; gevonden: $($InternalAddresses.Count)."
}

$InternalAddress = $InternalAddresses[0]

if ($InternalAddress.PrefixLength -ne 24) {
    throw "De interne interface heeft niet de verwachte prefix /24."
}

if ($InternalAddress.AddressState.ToString() -ne "Preferred") {
    throw "Het interne IP-adres is niet bruikbaar: $($InternalAddress.AddressState)."
}

$InternalIndex = $InternalAddress.InterfaceIndex

$InternalAdapter = Get-NetAdapter -InterfaceIndex $InternalIndex

if ($InternalAdapter.Status -ne "Up") {
    throw "De interne interface is niet actief."
}

$InternalDefaultRoutes = @(
    Get-NetRoute `
        -InterfaceIndex $InternalIndex `
        -AddressFamily IPv4 `
        -DestinationPrefix "0.0.0.0/0" `
        -PolicyStore ActiveStore
)

if ($InternalDefaultRoutes.Count -gt 0) {
    throw "De geselecteerde interne interface heeft een default-route. DNS wordt niet gewijzigd."
}

Write-Output (
    "Interne interface geselecteerd via IP-adres: {0}, index {1}" -f
    $InternalAdapter.Name, $InternalIndex
)

# Alleen op de gecontroleerde interne interface DNS instellen.
Set-DnsClientServerAddress `
    -InterfaceIndex $InternalIndex `
    -ServerAddresses "192.168.26.10", "192.168.26.20"

Write-Output "Server3 toevoegen aan domein $DomainName..."

$Result = Add-Computer `
    -DomainName $DomainName `
    -OUPath $OUPath `
    -Credential $Credential `
    -PassThru `
    -Verbose `
    -ErrorAction Stop

if (-not $Result.HasSucceeded) {
    throw "De domeinjoin is niet geslaagd."
}

Write-Output "Domeinjoin geslaagd. Vagrant moet server3 nu herstarten."

#Requires -RunAsAdministrator


<#
.SYNOPSIS
    Publiceert het publieke rootcertificaat van de Enterprise Root CA
    in Active Directory, zodat domeinleden de CA automatisch vertrouwen.
#>


param(
    [string]$DomainAdminUser = "WS26-JD\Administrator",
    [string]$DomainAdminPassword = "JouwSterkWachtwoord123!",
    [string]$CACommonName = "WS26-JD-Root-CA"
)


$ErrorActionPreference = "Stop"


$CertificatePath = "C:\LabCertificates\$CACommonName.cer"


if (-not (Test-Path $CertificatePath)) {
    throw "Rootcertificaat ontbreekt: $CertificatePath"
}


$TaskName = "WS2-PublishRootCA"
$LogFile = "C:\ProgramData\WS2-PublishRootCA.log"


# Verwijder een eventueel oud logbestand.
Remove-Item -Path $LogFile -Force -ErrorAction SilentlyContinue


# Gebruik cmd.exe zodat de omleiding eenvoudig en betrouwbaar is.
$TaskArguments = "/c certutil -f -dspublish `"$CertificatePath`" RootCA > `"$LogFile`" 2>&1"


$Action = New-ScheduledTaskAction `
    -Execute "$env:SystemRoot\System32\cmd.exe" `
    -Argument $TaskArguments


$Settings = New-ScheduledTaskSettingsSet `
    -ExecutionTimeLimit (New-TimeSpan -Minutes 5) `
    -AllowStartIfOnBatteries `
    -DontStopIfGoingOnBatteries


Register-ScheduledTask `
    -TaskName $TaskName `
    -Action $Action `
    -Settings $Settings `
    -User $DomainAdminUser `
    -Password $DomainAdminPassword `
    -RunLevel Highest `
    -Force `
    -ErrorAction Stop |
    Out-Null


try {
    Start-ScheduledTask -TaskName $TaskName -ErrorAction Stop


    $Deadline = (Get-Date).AddMinutes(2)


    do {
        Start-Sleep -Seconds 3


        $Task = Get-ScheduledTask -TaskName $TaskName -ErrorAction Stop
        $TaskInfo = Get-ScheduledTaskInfo -TaskName $TaskName -ErrorAction Stop


        $TaskState = $Task.State.ToString()
        $LastResult = $TaskInfo.LastTaskResult
    }
    while (
        $TaskState -in @("Running", "Queued") -and
        (Get-Date) -lt $Deadline
    )


    Write-Output "Taakstatus: $TaskState"
    Write-Output "Laatste taakresultaat: $LastResult"


    if (-not (Test-Path $LogFile)) {
        throw "Publicatielog ontbreekt: $LogFile"
    }


    $LogContent = Get-Content $LogFile -Raw


    Write-Output $LogContent


    if ($LogContent -notmatch "dsPublish command completed successfully") {
        throw "Publicatie van het rootcertificaat is mislukt."
    }


    Write-Output "Root-CA-certificaat is gepubliceerd in Active Directory."
}
finally {
    Unregister-ScheduledTask `
        -TaskName $TaskName `
        -Confirm:$false `
        -ErrorAction SilentlyContinue
}
